# ツーリング相棒

バイク+Bluetoothインカム向けの、ハンズフリー音声会話エージェント(PWA)です。
走行中に画面を一切触らず、声だけで雑談・周辺ガイド・音声メモができます。

- **雑談相手** — 眠気防止の話し相手。話題振りやクイズも。
- **周辺ガイド** — GPSの現在地・進行方向をもとに「この辺の道の駅は?」に答える。
- **音声メモ** — 「メモして◯◯」で時刻・位置付きのメモを保存。後で一覧・コピー・共有。

会話AIには [Claude API](https://console.anthropic.com/)(Claude Haiku 4.5)を使用します。
音声認識・読み上げはOS標準機能(Web Speech API)なので追加コストはかかりません。

## 動作環境

- **Android + Chrome を推奨**(音声認識の連続リッスンが安定しているため)
- iOS Safari は音声認識の制約が多く、動作保証外です
- ヘルメットのBluetoothインカム(B+COM / SENA 等)をスマホに接続して使います

## セットアップ

このブランチはルートが宅建一問一答アプリ、`touring/` フォルダがこのアプリという構成です。
GitHub Pagesでこのブランチを公開すると、次の2つのURLで両アプリが使えます。

- 宅建一問一答: `https://<ユーザー名>.github.io/bus-guide/`
- ツーリング相棒: `https://<ユーザー名>.github.io/bus-guide/touring/`

1. GitHub Pages(Settings → Pages)でこのブランチ+`/ (root)` を公開し、スマホのChromeで `…/touring/` を開く
2. メニューから「ホーム画面に追加」でインストール(任意)
3. ⚙️設定を開き、**Claude APIキー** を入力([Anthropic Console](https://console.anthropic.com/) で取得)
4. 必要に応じて設定:
   - **会話モード**: 常時会話 / ウェイクワード(初期値「ねえ相棒」)
     - インカム仲間との会話を拾わせたくない場合はウェイクワード推奨
   - **Web検索**: ONにすると営業時間・天気など最新情報に対応(1,000検索あたり$10)
   - **GPS位置情報**: 周辺ガイドに必要(会話のたびに現在地がAnthropic APIへ送られます)
   - **読み上げの声・速さ**

## 使い方

1. 出発前にインカムを接続し、マイク・位置情報の許可を済ませる
2. 中央の大きなボタンをタップ → 「準備できました」と聞こえたら走り出してOK
3. あとは話しかけるだけ:
   - 「なんか面白い話して」
   - 「この辺でおすすめの昼メシは?」
   - 「メモして、あとで◯◯のワインディングをもう一回走る」
4. AIが話している最中や考え中に止めたいときは、大ボタンをタップ(停車中に)

画面は消灯しないよう自動制御されます(Wake Lock)。画面が消えると音声認識が止まるため、走行中はスマホを給電しながらの利用を推奨します。

## データの扱い

- APIキー・メモ・会話履歴はすべて**端末内(localStorage)のみ**に保存されます
- 会話内容と現在地(GPS ON時)は応答生成のためAnthropic APIに送信されます
- 会話履歴はセッション単位で保存され、6時間以上空くと自動的に新しい会話になります

## ⚠️ 安全上の注意

- **走行中は絶対に画面を注視・操作しないでください。** 操作はすべて停車中に行ってください
- 音声への集中で注意力が下がると感じたら、すぐに利用をやめてください
- 各都道府県の道路交通法規(ながら運転規制等)を遵守してください

## 技術メモ

- ビルド不要の素のHTML/CSS/JS。PWA(Service Worker でアプリシェルをキャッシュ)
- 音声認識: `webkitSpeechRecognition`(連続モード+自動再開)。読み上げ中はマイクを止めてエコーを防止
- 読み上げ: `speechSynthesis`。ストリーミング応答を文単位で分割し、生成と並行して読み上げ開始
- Claude API はブラウザから直接呼び出し(`anthropic-dangerous-direct-browser-access` ヘッダー使用)
- メモ保存はツール(`save_memo`)経由、Web検索はサーバーツール(`web_search`)を設定に応じて有効化
