# 宅建一問一答 📱

忘却曲線に合わせて復習できる、宅建士試験のための一問一答スマホアプリ（PWA）です。
学習科学のエビデンス（想起練習・分散学習）に基づく設計で、スケジューリングにはAnkiが標準採用している **FSRS**（難易度・安定性・検索可能性の三成分モデル）を実装しています。「目標保持率」（既定90%、80〜97%で調整可）を満たすように、忘れる直前の間隔で再出題します。

## 収録内容

問題は同梱していません。お手持ちの教材を、設定画面のインポート機能（画像カードのZIP一括追加／テキスト貼り付け／JSON）で取り込んで使います。手順は `IMPORT_GUIDE.md` を参照してください。取り込んだデータは端末内にのみ保存されます。

## 使い方

### 公開する（GitHub Pages）

1. GitHubのリポジトリ設定 → **Settings → Pages** を開く
2. Source で対象ブランチと `/ (root)` を選んで保存
3. 表示されたURLをスマホで開く

### スマホのホーム画面に追加（アプリ化）

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー → 「ホーム画面に追加」/「アプリをインストール」

追加後はオフラインでも動作し、学習データは端末内（localStorage）に保存されます。

### 学習の流れ

1. ホームで「学習を始める」をタップ（復習期限が来た問題＋新規問題が出題されます）
2. 問題文が正しければ「○」、誤りなら「×」をタップ
3. 解説を読み、正解した場合は思い出しやすさを「難しい・普通・簡単」で評価
   - 評価に応じて次の出題日が自動計算されます（1日 → 3日 → 1週間 → 1か月…）
   - 間違えた問題は同じセッション内でもう一度出題され、翌日も再出題されます
4. 毎日アプリを開いて、その日の復習をこなすのが最も効率的です

## お手持ちの問題集（PDF 1000問など）の取り込み

設定画面の「問題の追加」に、次の形式のJSONを貼り付けると問題を追加できます。

```json
[
  {"q": "問題文をここに", "a": true, "exp": "解説をここに", "cat": "宅建業法"},
  {"q": "誤りの記述の例", "a": false, "exp": "解説", "cat": "権利関係"}
]
```

- `a`: 記述が正しければ `true`（○）、誤りなら `false`（×）
- `cat`: `宅建業法` / `権利関係` / `法令上の制限` / `税・その他`

また、テキスト形式（`Q. 問題文` / `A. ○ 解説` の並び）での貼り付けや、教材ページのスクショから問題・解答を切り出す**画像カード機能**（Anki方式の自己評価で出題）にも対応しています。詳しい手順は `IMPORT_GUIDE.md` を参照してください。取り込んだデータは端末内にのみ保存されます。市販教材から取り込んだ内容を配布・公開しないでください。

## デバイス間同期

設定画面からGitHubトークン（gist権限のみ）を登録すると、非公開Gist経由でスマホ・PC・タブレット間の学習記録を自動同期できます。手順は `IMPORT_GUIDE.md` を参照してください。

## データのバックアップ

学習データは端末のブラウザ内にのみ保存されます。機種変更やブラウザのデータ削除に備えて、設定画面から「バックアップ書出し」でJSONファイルを保存し、新しい端末で「読込み」してください。

## ファイル構成

```
index.html   … 画面（UI）
app.js       … アプリ本体（SRSアルゴリズム・画面制御）
data.js      … 問題データ（210問）
sw.js        … オフライン対応（Service Worker）
manifest.json… PWA設定
icon.svg     … アプリアイコン
```

問題データは `data.js` を直接編集しても追加・修正できます。
